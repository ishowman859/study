what is the tcp/ip?

  tcp/ip is transmission control protocol/internet protocol

how it works?

  1.application layer

  2. transport layer - tcp

  **TCP** chops it up into smaller pieces called **packets**


  3.internet layer -ip
  **IP** takes each packet and stamps a destination address (the IP address) on it

  4. network access layer
     The packets are turned into physical signals (electricity over Ethernet cables,
     light over fiber optics, or radio waves over Wi-Fi) and sent across the physical network.
